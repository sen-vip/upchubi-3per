# 업추비 3%

서울특별시교육청 학교회계의 **학교운영경비 대비 일반업무추진비 3% 이내 편성 여부**를 확인하는 학교 행정실용 도구입니다.

> 현재 버전 **v0.1.6**

## 📌 어떤 도구인가요?

학교회계 예산편성 시 일반업무추진비가 학교운영경비의 3% 이내로 편성되었는지 확인합니다.

에듀파인에서 내려받은 집행실적 엑셀파일을 그대로 불러오면 필요한 금액을 찾아 자동으로 계산합니다.

별도의 금액 입력이나 엑셀 가공 없이 확인할 수 있습니다.

## 📂 어떤 파일이 필요한가요?

에듀파인에서 **집행실적 엑셀파일 1개**를 내려받습니다.

경로

`학교회계 > 예산결산 > 결산현황 > 집행실적 > 엑셀저장`

엑셀파일 안의 다음 두 시트를 사용합니다.

- `세입실적`
- `성질별 세출실적`

## 🚀 사용방법

1. 에듀파인에서 집행실적 엑셀파일을 내려받습니다.
2. `세입실적` 파일을 업로드합니다.
3. `성질별 세출실적` 파일을 업로드합니다.
4. 두 자료가 확인되면 자동으로 결과를 계산합니다.
5. 학교운영경비, 3% 편성한도, 일반업무추진비 금액을 확인합니다.

## 🧮 계산 기준

분모는 **학교운영경비**입니다.

다음 원가통계목의 예산액을 합산합니다.

- 학교운영비전입금
- 사용료
- 수수료
- 자산매각대
- 지난년도수입
- 이자수입
- 기타행정활동수입
- 순세계잉여금

분자는 업무추진비 중 **일반업무추진비**만 사용합니다.

- 일반업무추진비 포함
- 목적사업 업무추진비 제외
- 직책급업무추진비 제외

편성한도는 다음과 같이 계산합니다.

`학교운영경비 × 3%`

## 🏫 적용 범위

현재 도구는 **서울특별시교육청 학교회계 기준**으로 제작되었습니다.

다른 시·도교육청은 업무추진비 편성 기준이 다를 수 있으므로 해당 교육청의 예산편성 지침을 확인해 주세요.

## 🔒 개인정보 및 파일 처리

업로드한 엑셀파일은 브라우저에서만 처리합니다.

파일을 서버에 저장하거나 별도로 전송하지 않습니다.

## ℹ️ 안내

이 결과는 업로드한 자료를 기준으로 계산한 확인용 참고자료입니다.

실제 편성 시에는 해당 연도 예산편성 지침과 학교회계 기준을 함께 확인해 주세요.
