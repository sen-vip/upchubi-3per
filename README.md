# 업추비 3%

학교운영경비 대비 일반업무추진비의 3% 이내 편성 여부를 확인하는 학교 행정실용 도구입니다.

## v0.1.3

- 결과 및 산출내역 하단에 확인용 참고자료 안내문구 추가
- 안내문구는 경고색 대신 옅은 청록·회색 톤으로 표시
- 도움말 화면 예시 이미지 파일을 배포 ZIP에 포함
- 파비콘 파일을 배포 ZIP에 포함

## 자료 다운로드 경로

학교회계 > 예산결산 > 결산현황 > 집행실적 > 엑셀저장(마감)

- `[세입실적]` 탭: 학교운영경비 계산용
- `[성질별 세출실적]` 탭: 일반업무추진비 계산용

## 계산 기준

학교운영경비는 다음 8개 세입 원가통계비목의 예산액 합계입니다.

- 학교운영비전입금
- 사용료
- 수수료
- 자산매각대
- 지난년도수입
- 이자수입
- 기타행정활동수입
- 순세계잉여금

업무추진비는 `B200101 일반업무추진비`의 예산액만 포함합니다.
직책급업무수행경비 및 목적사업업무추진비는 제외합니다.

## 실행

압축을 푼 뒤 `index.html`을 실행하면 첫 화면을 바로 확인할 수 있습니다.
엑셀 분석 기능은 SheetJS를 CDN에서 불러오므로 실제 파일 업로드 시 인터넷 연결이 필요합니다.
