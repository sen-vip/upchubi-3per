# 업추비 3%

**학교회계 엑셀 두 개를 불러오면 학교운영경비 대비 일반업무추진비가 3% 이내로 편성되어 있는지 확인하는 웹 도구입니다.**

추경 후 학교운영경비가 달라졌을 때도 현재 자료를 다시 불러와 편성비율을 간단히 확인할 수 있습니다.

> 현재 버전 **v0.1.4**

---

## 📂 어떤 파일이 필요한가요?

에듀파인에서 다음 경로로 이동합니다.

`학교회계 → 예산결산 → 결산현황 → 집행실적 → 엑셀저장(마감)`

집행실적 화면에서 아래 두 파일을 각각 내려받아 주세요.

### 세입실적

**[세입실적] 탭**에서 엑셀 파일을 내려받습니다.

학교운영경비 계산에 사용합니다.

### 성질별 세출실적

**[성질별 세출실적] 탭**에서 엑셀 파일을 내려받습니다.

일반업무추진비 계산에 사용합니다.

---

## 🚀 사용 방법

1. 세입실적 파일을 불러옵니다.
2. 성질별 세출실적 파일을 불러옵니다.
3. 두 파일이 확인되면 자동으로 계산합니다.

파일명에 3월, 7월, 2월처럼 시점이 표시되어 있지 않아도 괜찮습니다.

업추비 3%는 파일명이나 월을 판단하지 않고  
**현재 불러온 엑셀의 예산액을 기준으로 계산합니다.**

---

## 🔎 무엇을 확인하나요?

결과 화면에서 다음 내용을 확인할 수 있습니다.

- 학교운영경비
- 학교운영경비의 3% 기준액
- 일반업무추진비 편성액
- 업무추진비 편성비율
- 3% 이내 여부
- 학교운영경비 산출내역
- 일반업무추진비 산출근거

---

## 🧮 학교운영경비는 어떻게 계산하나요?

세입실적 파일의 예산액 중 다음 8개 원가통계비목만 합산합니다.

- 학교운영비전입금
- 사용료
- 수수료
- 자산매각대
- 지난년도수입
- 이자수입
- 기타행정활동수입
- 순세계잉여금

위 8개 항목의 합계가 학교운영경비입니다.

목적사업비전입금, 수익자부담수입 등 다른 세입이 증가하더라도  
위 8개 항목에 해당하지 않으면 계산에 포함하지 않습니다.

따라서 추경으로 학교 전체 세입예산이 증가해도  
학교운영경비는 그대로일 수 있습니다.

---

## 💼 일반업무추진비는 어떻게 계산하나요?

성질별 세출실적 파일에서 다음 항목의 예산액만 계산합니다.

`업무추진비 → 일반업무추진비 → 일반업무추진비`

원가통계비목코드 기준으로는 **B200101**입니다.

다음 항목은 계산에서 제외합니다.

- 직책급업무수행경비
- 목적사업업무추진비

---

## 📐 계산 기준

편성비율은 다음과 같이 계산합니다.

`일반업무추진비 ÷ 학교운영경비 × 100`

3% 기준액은 다음과 같이 계산합니다.

`학교운영경비 × 3%`

화면에 표시되는 비율은 보기 쉽게 반올림될 수 있으므로  
3% 이내 여부는 실제 금액을 기준으로 계산합니다.

---

## 🔄 추경 후에도 사용할 수 있나요?

네.

추경 후 새로 내려받은 세입실적과 성질별 세출실적 파일을 다시 불러오면  
변경된 현재 예산액을 기준으로 다시 계산합니다.

학교 전체 예산이 증가했는지가 아니라  
**학교운영경비에 해당하는 8개 원가통계비목이 실제로 변경되었는지**가 중요합니다.

---

## 🔒 파일은 어디로 가나요?

불러온 엑셀 파일은 서버에 저장하지 않습니다.

파일 내용은 현재 브라우저에서 직접 읽고 계산합니다.

- 회원가입 없음
- 엑셀 원본 서버 저장 없음
- 별도 데이터베이스 저장 없음

페이지를 새로고침하거나 처음부터 다시 시작하면 불러온 자료를 비울 수 있습니다.

---

## ℹ️ 안내

이 결과는 업로드한 자료를 기준으로 계산한 확인용 참고자료입니다.  
실제 편성 시에는 해당 연도 예산편성 지침과 학교회계 기준을 함께 확인해 주세요.

---

## 🛠️ 파일이 안 불러와질 때

다음 내용을 먼저 확인해 주세요.

1. 에듀파인 집행실적에서 내려받은 원본 엑셀인지 확인합니다.
2. [세입실적] 파일과 [성질별 세출실적] 파일을 각각 준비했는지 확인합니다.
3. 엑셀의 열 제목이나 구조를 임의로 크게 수정하지 않았는지 확인합니다.
4. 페이지를 새로고침한 뒤 다시 불러옵니다.

계속 문제가 있다면 개인정보를 제거한 화면 캡처와 오류 상황을 함께 남겨주세요.
