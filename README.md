# 💰 업추비 3%

**서울특별시교육청 학교회계 엑셀 두 개를 불러오면 학교운영경비 대비 일반업무추진비가 3% 이내로 편성되어 있는지 확인하는 웹 도구입니다.**

복잡한 계산 없이 에듀파인에서 내려받은 **세입실적**과 **성질별 세출실적**을 그대로 올리면 현재 자료 기준 편성비율과 산출내역을 보여줍니다.

> 현재 버전 **v0.1.5**

서울특별시교육청 학교회계 예산편성 기준을 대상으로 합니다. 다른 시·도교육청은 해당 교육청의 예산편성 지침을 확인해 주세요.

---

## 가장 빠른 사용 방법

### 1. 에듀파인에서 파일 두 개 내려받기

다음 경로로 이동합니다.

`학교회계 → 예산결산 → 결산현황 → 집행실적 → 엑셀저장(마감)`

같은 화면에서 다음 두 파일을 각각 내려받습니다.

- **[세입실적] 탭** → 학교운영경비 계산용
- **[성질별 세출실적] 탭** → 일반업무추진비 계산용

파일명에 월이나 회계 시점이 표시되어 있지 않아도 됩니다.
업추비 3%는 파일명으로 시점을 판단하지 않고 **업로드한 파일 안의 현재 예산액**을 기준으로 계산합니다.

### 2. 파일 두 개 불러오기

메인 화면의 각 업로드 영역에 파일을 끌어놓거나 클릭해서 선택합니다.

- 세입실적
- 성질별 세출실적

파일이 정상적으로 확인되면 두 자료를 자동으로 계산해 결과를 보여줍니다.

### 3. 결과 확인하기

결과에서는 다음 내용을 바로 확인할 수 있습니다.

- 학교운영경비
- 3% 편성 기준액
- 일반업무추진비
- 현재 편성비율
- 3% 이내 여부
- 학교운영경비 8개 항목 산출내역
- 일반업무추진비 포함·제외 기준

---

## 학교운영경비는 이렇게 계산합니다

세입실적 파일의 **예산액** 가운데 다음 8개 원가통계비목만 합산합니다.

- 학교운영비전입금
- 사용료
- 수수료
- 자산매각대
- 지난년도수입
- 이자수입
- 기타행정활동수입
- 순세계잉여금

전체 세입예산을 기준으로 계산하지 않습니다.
목적사업비전입금이나 수익자부담수입 등이 늘어도 위 8개 항목에 변화가 없다면 학교운영경비는 달라지지 않을 수 있습니다.

---

## 일반업무추진비는 이것만 봅니다

세출실적 성질별 파일에서 다음 항목의 **예산액**만 계산합니다.

`업무추진비 → 일반업무추진비 → 일반업무추진비 (B200101)`

다음 항목은 포함하지 않습니다.

- 직책급업무수행경비
- 목적사업업무추진비

---

## 3% 여부는 이렇게 확인합니다

계산식은 다음과 같습니다.

`일반업무추진비 ÷ 학교운영경비 × 100`

화면에서는 편성비율을 읽기 쉽게 소수점 둘째 자리까지 표시하지만, **3% 이내 여부는 표시된 반올림 값이 아니라 실제 예산액과 3% 산출액을 비교해 확인합니다.**

예를 들어 화면에 `3.00%`로 보여도 실제 금액이 3% 산출액을 넘는 경우에는 `3% 초과`로 표시될 수 있습니다.

---

## 추경 후에도 같은 파일을 사용하면 됩니다

이 도구는 학기초 자료인지, 추경 후 자료인지, 회계말 자료인지 따로 선택하지 않습니다.

추경 후 다시 확인하고 싶다면 같은 경로에서 최신 **세입실적**과 **성질별 세출실적** 파일을 내려받아 다시 올리면 됩니다.
현재 업로드한 자료의 예산액을 기준으로 새로 계산합니다.

---

## 파일은 어디로 가나요?

**불러온 엑셀 원본은 별도 서버에 저장하지 않습니다.**

파일은 현재 브라우저에서 읽어 계산하며, 별도의 회원가입이나 데이터베이스 저장 기능이 없습니다.

> 로컬에서 `index.html`을 직접 실행하는 경우 엑셀 읽기 기능에 사용하는 SheetJS를 불러오기 위해 인터넷 연결이 필요합니다.

---

## 파일이 안 불러와질 때

다음 내용을 먼저 확인해 주세요.

1. 에듀파인의 `집행실적 → 엑셀저장(마감)`에서 받은 파일인지 확인합니다.
2. `[세입실적]`과 `[성질별 세출실적]` 파일을 준비했는지 확인합니다.
3. 내려받은 엑셀의 열 제목이나 구조를 임의로 크게 수정하지 않았는지 확인합니다.
4. 새로고침 또는 `처음부터`를 누른 뒤 다시 불러옵니다.
