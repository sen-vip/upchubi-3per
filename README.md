# 업추비 3%

서울특별시교육청 학교회계 기준에 따라 **학교운영경비 대비 일반업무추진비가 3% 이내로 편성되어 있는지 확인하는 웹 도구**입니다.

에듀파인에서 내려받은 엑셀 파일을 올리거나, 파일이 없다면 금액을 직접 입력해 편성비율과 3% 기준액을 확인할 수 있습니다.

> 현재 버전: **v0.1.20**

서울특별시교육청 학교회계 예산편성 기준을 대상으로 합니다. 다른 시·도교육청은 해당 교육청의 예산편성 지침을 확인해 주세요.

---

## 📁 어떤 파일이 필요한가요?

에듀파인에서 다음 두 가지 방식 중 하나로 세입 자료 1개와 세출 자료 1개를 내려받습니다.

**마감 자료**

`학교회계 → 예산결산 → 결산현황 → 집행실적 → 엑셀저장(마감)`

- **[세입실적] 탭** → 학교운영경비 계산용
- **[성질별 세출실적] 탭** → 일반업무추진비 계산용

**실시간 자료**

`학교회계 → 예산결산 → 결산현황 → 집행실적 엑셀저장(실시간)`

- **201 · 목/원가목별 세입실적** → 학교운영경비 계산용
- **104 · 성질별 세출실적** → 일반업무추진비 계산용

실시간 화면에서는 201과 104를 각각 선택한 뒤 오른쪽 위 **[파일]** 버튼으로 엑셀 파일을 저장합니다.

파일을 올리면 파일명만 보지 않고, 파일 내부의 항목·원가통계비목코드·예산액 열을 확인해 자동으로 판별합니다.

---

## 🚀 사용 방법

### 파일 업로드

1. `파일 업로드` 탭을 선택합니다.
2. 세입실적 파일과 성질별 세출실적 파일을 각각 올립니다.
3. 두 파일이 확인되면 자동으로 계산 결과가 표시됩니다.

### 직접 입력

파일이 없다면 `직접 입력` 탭을 사용할 수 있습니다.

1. 학교운영경비를 입력합니다.
2. 일반업무추진비를 입력합니다.
3. `계산하기`를 누르면 같은 기준으로 3% 여부를 계산합니다.

직접 입력값은 계산에만 사용되며 별도로 저장되지 않습니다.

---

## 🧮 학교운영경비는 이렇게 계산합니다

세입실적 또는 201 형식 파일의 **예산액** 가운데 다음 8개 원가통계비목코드만 합산합니다.

- 학교운영비전입금
- 사용료
- 수수료
- 자산매각대
- 지난년도수입
- 이자수입
- 기타행정활동수입
- 순세계잉여금

전체 세입예산을 기준으로 계산하지 않습니다.

목적사업비전입금이나 수익자부담수입 등이 늘어도 위 8개 항목에 변화가 없다면 학교운영경비는 달라지지 않을 수 있습니다.

---

## 💼 일반업무추진비는 이것만 봅니다

성질별 세출실적 또는 104 형식 파일에서 다음 항목의 **예산액**만 계산합니다.

`업무추진비 → 일반업무추진비 → 일반업무추진비 (B200101)`

다음 항목은 포함하지 않습니다.

- 직책급업무수행경비
- 목적사업업무추진비

---

## 📊 3% 여부는 이렇게 확인합니다

계산식은 다음과 같습니다.

`일반업무추진비 ÷ 학교운영경비 × 100`

화면에서는 편성비율을 읽기 쉽게 소수점 둘째 자리까지 표시합니다.

다만 **3% 이내 여부는 화면에 표시되는 반올림 값이 아니라 실제 예산액과 3% 산출액을 비교해 판정합니다.**

따라서 화면에 `3.00%`로 표시되더라도 실제 편성액이 3% 산출액을 초과하면 `3% 초과`로 표시될 수 있습니다.

---

## ✏️ 금액을 수정해서 다시 계산할 수 있어요

파일을 업로드한 뒤 **학교운영경비 산출내역의 8개 원가통계비목을 각각 수정**할 수 있습니다.

예를 들어 `학교운영비전입금`만 변경하면 나머지 7개 항목은 파일에서 읽은 값을 그대로 유지하고, 변경된 금액을 반영해 학교운영경비 합계와 3% 편성한도를 즉시 다시 계산합니다.

일반업무추진비도 결과 화면의 `수정하기`에서 계산에 사용할 금액을 변경할 수 있습니다.

수정값은 현재 계산에만 사용되며 원본 엑셀 파일은 변경하지 않습니다. 학교운영경비 산출내역의 `파일 값으로 되돌리기`를 누르면 8개 항목의 보정값을 모두 없애고 업로드한 원래 값으로 돌아갑니다.

---

## 🔄 추경 후에도 다시 확인할 수 있어요

학기초, 추경 후, 회계말을 별도로 선택할 필요는 없습니다.

추경 후 다시 확인하려면 같은 에듀파인 경로에서 최신 세입실적과 성질별 세출실적 파일을 내려받아 다시 올리면 됩니다.

현재 업로드한 자료의 예산액을 기준으로 새로 계산합니다.

---

## ❓ 도움말

화면 상단의 `도움말`에서 다음 내용을 확인할 수 있습니다.

- 파일 업로드와 직접 입력 방법
- 에듀파인 파일 다운로드 경로
- 학교운영경비 계산 기준
- 일반업무추진비 포함·제외 기준

`파일은 여기서 내려받아요` 영역의 `파일 내려받는 방법`을 누르면 도움말의 파일 다운로드 안내로 바로 이동합니다.

---

## 🔒 파일과 입력값은 어디로 가나요?

업로드한 엑셀 원본과 직접 입력한 금액은 **별도 서버에 저장하지 않습니다.**

파일은 현재 브라우저에서 읽어 계산하며, 별도의 회원가입이나 데이터베이스 저장 기능이 없습니다.

> 로컬에서 `index.html`을 직접 실행하는 경우 엑셀 읽기 기능에 사용하는 SheetJS를 불러오기 위해 인터넷 연결이 필요합니다.

---

## 🛠️ 파일이 안 불러와질 때

다음 내용을 먼저 확인해 주세요.

1. 에듀파인의 집행실적에서 받은 엑셀 파일인지 확인합니다.
2. `[세입실적] + [성질별 세출실적]` 또는 `201 + 104` 형식의 세입·세출 파일을 준비했는지 확인합니다.
3. 내려받은 엑셀의 열 제목이나 구조를 임의로 크게 수정하지 않았는지 확인합니다.
4. 새로고침 또는 `처음부터`를 누른 뒤 다시 불러옵니다.

파일이 없다면 `직접 입력` 탭에서 학교운영경비와 일반업무추진비를 입력해 확인할 수 있습니다.
